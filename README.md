# 📈 Page View Time Series Visualizer

A Python time-series data visualization project built for **freeCodeCamp's Data Analysis with Python Certification**. This application analyzes daily forum page views on freeCodeCamp.org from May 2016 to December 2019 using **Pandas**, **Matplotlib**, and **Seaborn**.

---

## 📊 Visualizations Included

1. **Daily Page Views Line Plot (`line_plot.png`):** Displays daily visit traffic growth trends over time.
2. **Monthly Average Bar Plot (`bar_plot.png`):** Compares average daily page views for each month grouped across 2016-2019.
3. **Trend & Seasonality Box Plots (`box_plot.png`):** Features adjacent year-wise (trend) and month-wise (seasonality) distribution box plots.

---

## 🛠️ Tech Stack & Requirements

- **Language:** Python 3
- **Data Library:** Pandas (`import pandas as pd`)
- **Visualization Libraries:** Matplotlib, Seaborn
